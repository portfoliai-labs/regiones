regiones

Italy's real estate market data by zone (OMI quotations, zones, perimeters, sales), one file per municipality.

Source: «Agenzia delle Entrate – OMI», licensed under CC BY 4.0 (Forniture dati OMI); this dataset is CC BY 4.0 too. It is not published nor endorsed by the Agenzia delle Entrate. Changes: rearranged by municipality, perimeters simplified within about 3 m; see the manifest.

Start from v1/manifest.json. Layout and how to read it: github.com/portfoliai-labs/regiones.
